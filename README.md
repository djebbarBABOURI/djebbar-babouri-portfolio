# Portfolio React + Vite (FR/EN)

    npm install
    npm run dev      # développement
    npm run build    # production → dist/

1. Éditez `src/data.js` (infos, compétences, parcours, projets, textes FR/EN).
2. Ajoutez dans `public/` : `photo.jpg`, `cv-fr.pdf`, `cv-en.pdf`, `projects/*.png`.
3. Déployez `dist/` sur Netlify, Vercel ou GitHub Pages.
